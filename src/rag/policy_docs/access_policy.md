# System and Data Access Policy

**Policy Category:** Access
**Last Updated:** 2026-03-10

## Requesting Access to Internal Systems

Access to internal systems (shared drives, internal wikis, project management tools, customer data systems) is granted on a least-privilege basis. Employees must submit an access request specifying:

- The system or resource needed
- Business justification tied to their role
- Manager approval

Requests for systems containing customer data or financial records require an additional approval from the relevant Data Owner, in addition to manager approval.

## Access Reviews

All system access is reviewed quarterly by IT Security. Access that has not been used in 90 days is automatically flagged for removal unless the employee's manager confirms it is still required.

## Role Changes and Offboarding

When an employee changes roles internally, their previous access is not automatically carried over — a new access request reflecting the new role must be submitted. When an employee leaves the company, all system access is revoked on their last working day as part of the offboarding checklist.

## Elevated / Admin Access

Requests for administrator-level or elevated access (e.g. server admin, database admin) require both manager approval and IT Security sign-off, and are granted for a maximum of 90 days before requiring re-justification.

## Suspicious Access Requests

Any request for access to systems outside an employee's normal role or department, or any request made on behalf of another employee, should be escalated to a human IT agent for identity verification rather than processed automatically.
